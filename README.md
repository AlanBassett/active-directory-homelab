Active Directory Homelab

Overview

This project documents my hands-on experience building and administering a virtualized Active Directory environment.

The goal is to develop practical skills in Windows Server administration, identity and access management, networking, and cybersecurity.

Lab Environment

Host: HP Z2 Workstation

Hypervisor: VMware Workstation

Domain Controller: Windows Server

Domain: CORP (lab environment)

Additional VMs: Kali Linux

Documentation

Detailed walkthroughs, screenshots, configuration notes, and troubleshooting records will be added as the lab develops.
